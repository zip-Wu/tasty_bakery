# 囤囤馒头 · 功能需求文档

## 一、项目定位

面包店微信小程序，顾客扫码点单 → 线上支付 → 到店自提。配商家管理后台，老板用浏览器管理商品和订单。

---

## 二、已完成功能

### 顾客端（小程序）

| 模块 | 功能 | 状态 |
|------|------|------|
| 首页 | Banner 展示 + 门店自提入口 + 活动公告 | ✅ |
| 门店选择 | 地图展示门店 + 选择后进入点单 | ✅ |
| 商品浏览 | 按分类筛选（7类）、商品列表展示 | ✅ |
| 购物车 | 加减数量、自动计算总价 | ✅ |
| 下单 | 创建订单 → 跳转确认页 | ✅ |
| 支付 | 模拟支付（待接入真实微信支付） | ⚠️ 模拟 |
| 订单跟踪 | 5节点时间线（创建→支付→接单→制作完成→取餐） | ✅ |
| 订单列表 | 按状态筛选、角标数量、重新支付 | ✅ |
| 确认取餐 | 用户确认已取到餐品 | ✅ |
| 个人中心 | 用户信息展示、订单角标 | ✅ |

### 商家端（Web 后台）

| 模块 | 功能 | 状态 |
|------|------|------|
| 管理员登录 | 密码登录 / JWT 认证 | ✅ |
| 订单管理 | 查看全部订单、标记"可取餐" | ✅ |
| 商品管理 | 上下架开关、修改价格、修改名称 | ✅ |
| 营收看板 | 今日营收、订单数、分布统计 | ✅ |

### 技术栈

| 层 | 技术 |
|----|------|
| 前端 | 微信小程序原生（WXML/WXSS/JS） |
| 后端 | Node.js + Express |
| 数据库 | SQLite（better-sqlite3） |
| 认证 | JWT（管理后台） |
